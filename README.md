# Library Management System (C++ / OOP)

A console-based application to manage library operations like adding books, issuing books, and tracking records. Built using **C++** and **Object-Oriented Programming (OOP)** principles.

## Features
- **Student**: Borrow, return, and search books.
- **Librarian**: Add, update, and remove books.
- **Admin**: Manage users (students/librarians) and view reports.
- **File Handling**: Stores books, users, and borrowed books in `.txt` files.

## How to Run
1. Compile: `g++ main.cpp -o library`
2. Run:  
   - **Linux/Mac**: `./library`  
   - **Windows**: `library.exe`
